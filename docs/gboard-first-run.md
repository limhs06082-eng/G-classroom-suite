# G-board 처음 쓰기

교실 컴퓨터에 설치해 두고 하루 종일 켜 두는 프로그램입니다.

받아서 하실 일은 **설치 파일을 더블클릭하는 것 하나**입니다. 계정도, 가입도, 설정값도 없습니다.

---

## 1. 설치

1. 설치 파일(`G-board_0.0.0_x64-setup.exe`)을 내려받습니다
2. 더블클릭합니다

### "Windows의 PC 보호" 창이 뜨면

**정상입니다. 바이러스가 아닙니다.**

1. **추가 정보**를 누릅니다
2. **실행**을 누릅니다

한 번만 하면 다음부터는 안 물어봅니다.

> 개인이 만든 프로그램이라 마이크로소프트 인증서가 없어서 나오는 창입니다. 인증서는 해마다 수십만 원이 들어, 무료로 나눠 드리는 프로그램에는 붙이지 않았습니다. 쌤핀·스쿨보드도 같습니다.

---

## 2. 켜자마자 보이는 것

**마법사가 안 뜹니다.** 켜면 곧바로 첫 화면이 나오고, 아직 아무것도 없으니 카드들이 비어 있습니다. 그 **빈 카드가 무엇을 하면 채워지는지** 말해 줍니다.

```
오늘 급식     "학교를 정하면 오늘 급식이 여기 나옵니다"   [학교 찾기]
오늘 시간표   "시간표를 한 번 짜 두면 여기 나옵니다"      [시간표 짜기]
```

순서대로 안 하셔도 됩니다. 하나도 안 하셔도 앱은 돕니다.

---

## 3. 처음에 해 두면 좋은 것 셋

### 학교 정하기 (설정 → 학교 정보)

학교 **이름으로 검색**해서 고르시면 됩니다. 코드를 아실 필요 없습니다.

고르시면 **급식과 날씨가 함께 따라옵니다.** 지역을 따로 안 물어봅니다.

> 같은 이름의 학교가 여럿이면 교육청과 주소를 보고 고르세요. 잘못 고르셨으면 다시 고르시면 되고, 앞 학교 급식은 저절로 지워집니다.
>
> 검색 결과는 **한 번에 다섯 곳까지만** 나옵니다. 자기 학교가 안 보이면 이름을 더 길게 넣어 보세요. (NEIS가 정한 제한입니다)

### 학급 만들기 (설정 → 학급·학기)

학년과 반을 적으시면 시간표의 과목 단추가 **그 학년에 맞게** 나옵니다. 1·2학년은 통합교과가, 5·6학년은 실과가 나옵니다.

### 시간표 짜기 (설정 → 시간표)

**과목을 먼저 고르고 칸을 찍습니다.** 국어를 한 번 고르고 국어 칸을 쭉 찍으면 됩니다. 칸마다 고르는 것보다 훨씬 빠릅니다.

- 찍은 칸을 다시 누르면 지워집니다
- 빈 칸은 "그날 그 교시가 없다"는 뜻입니다
- 안 쓰는 교시는 표 아래 시정표에서 ✕로 지우면 됩니다
- 목록에 없는 과목은 직접 입력하면 그때부터 단추가 됩니다

시간표를 짜 두시면 첫 화면의 **'지금' 카드**가 켜집니다 — `3교시 수학 · 12분 남음`처럼 나오고, 그 자리에서 전자칠판·타이머·화면 가리개를 바로 열 수 있습니다.

---

## 4. 인터넷이 필요한가요

**학급 자료는 필요 없습니다.** 학생 명단·자리·당번·보상·과제는 전부 이 컴퓨터 안에서 돌고, 인터넷이 끊겨도 그대로 씁니다.

**급식과 날씨는 필요합니다.** 바깥에서 받아 오는 것이라 그렇습니다.

- 급식은 한 번 받아 두면 담아 둡니다. **인터넷이 끊긴 날에도 그날 급식은 보입니다**
- 날씨는 한 시간마다 새로 받습니다. 못 받으면 마지막에 받은 것을 그대로 둡니다

---

## 5. 자료는 어디에 있나요

```
C:\Users\(사용자 이름)\AppData\Roaming\net.ssamdongne.gboard\
```

이 폴더의 **`data.json` 하나**가 학급 자료 전부입니다. USB나 클라우드에 복사해 두면 그것으로 백업이 됩니다.

앱 안에서는 **설정 → 백업·복원**에서 파일로 내려받을 수 있습니다.

> 같은 폴더의 `cache.json`은 급식과 날씨를 담아 둔 것이라 백업할 필요 없습니다. 지워도 다시 받아 옵니다.

---

## 6. 알아 두시면 좋은 것

**전자칠판은 두 번째 모니터에 뜹니다.** 교실 앞 화면에 띄우는 용도라, 선생님 모니터는 그대로 두고 그쪽에만 전체 화면으로 나갑니다.

> 모니터가 하나뿐이면 **그 화면에 전체 화면으로** 뜹니다. 닫으시면 원래대로 돌아옵니다.

**화면 색을 고를 수 있습니다** (설정 → 화면). 넷이고, 취향이 아니라 상황으로 나눴습니다.

| | 언제 |
|---|---|
| 밝게 | 교실 불을 켜 둔 보통 때 |
| 포근하게 | 종일 켜 두는 화면. 눈이 덜 시립니다 |
| 어둡게 | 불 끄고 영상 볼 때, 이른 아침 |
| **또렷하게** | **프로젝터·전자칠판.** 교실 뒤에서도 읽힙니다 |

**앱을 두 번 켜도 창은 하나입니다.** 바탕화면 아이콘을 두 번 누르셔도 이미 열린 창이 앞으로 나옵니다.

**형성평가는 없습니다.** 학생 기기가 필요한 기능이라 설치형에서는 빼고, 웹앱 쪽으로 안내합니다.

---

## 7. 새 판이 나오면

새 설치 파일을 **덮어씌우시면 됩니다.** 학급 자료·시간표·설정은 그대로 남습니다. 지우고 다시 설치하지 않으셔도 됩니다.

---

## 잘 안 될 때

| 이러면 | 이렇게 |
|---|---|
| 급식이 "받아 오지 못했습니다" | 인터넷 연결을 확인해 주세요 |
| 급식이 "오늘은 급식이 없습니다"인데 급식이 있다 | 학교를 다시 골라 보세요. 같은 이름의 다른 학교일 수 있습니다 |
| '지금' 카드가 안 뜬다 | 시간표를 짜셨는지, 오늘 요일 줄이 채워졌는지 보세요 |
| 날씨가 안 뜬다 | 학교를 고르셨는지 보세요. 주소에서 지역을 뽑습니다 |
| 자료가 사라진 것 같다 | 설정 → 백업·복원에 자동 백업이 남아 있습니다 |
