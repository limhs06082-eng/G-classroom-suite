# G-board 설치하기

## 받아서 실행하기

1. 설치 파일(`G-board_x.x.x_x64-setup.exe`)을 내려받습니다
2. 더블클릭합니다

## "Windows의 PC 보호" 창이 뜨면

**정상입니다. 바이러스가 아닙니다.**

개인이 만든 프로그램이라 마이크로소프트 인증서가 없습니다. 인증서는
해마다 수십만 원이 들어서, 무료로 나눠 드리는 프로그램에는 붙이지
않았습니다. 쌤핀·스쿨보드도 같은 방식입니다.

1. **추가 정보**를 누릅니다
2. **실행**을 누릅니다

한 번만 하면 다음부터는 안 물어봅니다.

## 자료는 어디에 있나요

`C:\Users\(사용자 이름)\AppData\Roaming\net.ssamdongne.gboard\`

이 폴더의 **`data.json` 하나**가 학급 자료 전부입니다. USB나 클라우드에
복사해 두면 그것으로 백업이 됩니다.

앱 안에서는 **설정 → 백업·복원**에서 내려받을 수 있습니다.

## 인터넷이 필요한가요

**아니요.** 자료는 이 컴퓨터에만 있고, 인터넷 없이 모든 기능이 돕니다.

## 아직 사람이 확인해야 하는 것

여기까지는 자동 검사로 확인했습니다. 아래는 자동 검사가 끝까지 볼 수
없어서, 설치한 뒤 사람이 직접 눈으로 봐야 하는 것들입니다.

- 앱을 켜면 `G-board` 제목의 창이 뜨고, 1024×700보다 작게 줄어들지 않는다
- 학급을 만들고 앱을 껐다 켜면 그대로 남아 있다
- 자리·모둠에서 [전자칠판]을 누르면 크롬이 아니라 **앱 창**이 뜬다
- 모니터가 둘이면 전자칠판이 두 번째 모니터에 전체 화면으로 뜬다
- 전자칠판을 열어 둔 채 교사 창에서 자리를 바꾸면 칠판이 1초 안에 따라온다
- 전자칠판 창을 닫아도 교사 창이 멀쩡하다
- 개발자 도구 콘솔에 같은 메시지가 끝없이 찍히지 않는다
- 형성평가가 홈에도 헤더에도 없고, 대신 웹으로 가는 안내가 보인다
- 자료를 고친 직후 창을 닫았다가 다시 켜도 마지막 변경이 남아 있다
- 설정 → 백업·복원에서 백업 파일 내려받기를 눌렀을 때 실제로 파일이 저장된다
- 개발자 도구 콘솔(Ctrl+Shift+I)에 저장 실패 경고가 없다
- 앱이 이미 켜져 있을 때 아이콘을 한 번 더 눌러도 창이 두 개 뜨지 않고, 이미 열린 창이 앞으로 나온다
- `Ctrl+Shift+I`로 개발자 도구가 열린다 (2판 동안만. 3판에서 끈다)
- 개발자 도구 콘솔에 `Content Security Policy` 위반이 하나도 없다
- 설정 → 학교 정보에서 학교 이름으로 검색하면 목록이 뜨고, 고르면 코드가 저절로 채워진다
- 학교를 정한 뒤 홈에 오늘 급식이 뜬다
- 인터넷을 끊고 앱을 다시 켜도 어제 본 급식이 그대로 보인다
- 방학·주말이면 "오늘은 급식이 없습니다"라고 나온다 (오류가 아니다)
- 설정 → 시간표에서 과목을 고르고 칸을 찍으면 들어간다
- 같은 칸을 다시 누르면 지워진다
- 직접 입력한 과목이 단추로 남는다
- 홈 화면에 오늘 요일의 교시가 순서대로 뜬다
