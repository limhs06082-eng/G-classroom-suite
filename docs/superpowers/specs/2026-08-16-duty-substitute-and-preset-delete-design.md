# 당번 대체 지정과 행동 항목 정리 설계

**날짜** 2026-08-16
**적용 대상** `G-classroom-suite` — `features/duty` · `features/reward`
**계기** 점검 스크립트가 찾은 훅 미사용 API 둘. 배포 전 마무리.

---

## 1. 무엇을 고치나

| 지금 | 문제 |
|---|---|
| `useDuty.setSubstitute`를 부르는 화면이 없다 | **대체자를 보여 주기는 하는데 지정할 수가 없다** |
| `useReward.deletePreset`을 부르는 화면이 없다 | 행동 항목을 만들 수는 있는데 지울 수 없다 |

### 1.1 당번 대체는 절반만 이식됐다

`DutyPage`와 `DutyBoard`가 이미 대체자를 읽어 표시한다 — 학생 이름 옆에
`{원래 학생} 대신` 배지가 뜬다. `useDuty`가 `replaced`를 계산해 내주고 있고,
`DutyCompletion.substitutions`도 저장·복원된다.

**넣을 방법만 없다.** 이 프로젝트에서 여러 번 본 모양이다 — 읽는 쪽은 옮겨졌고
쓰는 쪽이 안 옮겨졌다. 표시 코드가 있으니 화면만 붙이면 바로 살아난다.

---

## 2. 두 곳 모두 중첩 버튼을 만들기 쉬운 자리다

방금 `ClassroomGrid`에서 좌석 버튼 안의 자물쇠 버튼을 걷어냈다.
여기서 같은 실수를 반복하기 쉽다.

| 곳 | 이미 버튼인 것 | 안 되는 방법 |
|---|---|---|
| 당번 학생 줄 | 줄 전체가 완료 토글 버튼 | 줄 안에 `대체` 버튼 넣기 |
| 행동 항목 칩 | 칩 전체가 선택 버튼 | 칩 안에 `X` 버튼 넣기 |

**둘 다 "버튼 안에 버튼"이 된다.** 유효하지 않은 HTML이고 브라우저마다
탭 순서와 화면 낭독기 동작이 달라진다.

---

## 3. 당번 대체 — 역할 카드 머리에 버튼, 지정은 모달에서

학생 줄은 그대로 둔다. **역할 카드 머리**에 `대체` 버튼을 더한다.
거기에는 이미 자물쇠 버튼이 있고 학생 줄과 형제라 중첩이 아니다.

누르면 모달이 열린다.

> **{역할 이름} 오늘 대체**
> 원래 당번마다 대신할 학생을 고릅니다.
>
> | 원래 당번 | 대신할 학생 |
> |---|---|
> | 3 박세찬 | `(대체 없음) ▾` |

`<select>`를 쓴다. 터치에서도 잘 되고 코드가 짧다.
목록에는 **오늘 그 역할에 배정되지 않은 재학생만** 담는다 —
당번인 학생이 자기 대신 다른 당번을 하는 것은 대체가 아니다.

`(대체 없음)`을 고르면 `setSubstitute(..., null)`로 지운다.

### 3.1 오늘 하루만이다

`DutyCompletion`은 날짜별 기록이라 대체도 그날치다. **다음 날이면 원래
당번으로 돌아온다.** 결석·조퇴 때문에 하루 바꾸는 것이 이 기능의 쓸모다.

모달에 그렇게 적는다.

> 오늘({날짜})만 바뀝니다. 내일은 원래 당번으로 돌아옵니다.

---

## 4. 행동 항목 정리 — 정리 모드 토글

칩 안에 삭제 버튼을 넣지 않는다. 대신 `항목 정리` 토글을 둔다.

| 모드 | 칩을 누르면 |
|---|---|
| 평소 | 그 항목을 골라 점수를 준다 |
| 정리 | 그 항목을 지울지 묻는다 |

정리 모드에서는 칩의 `aria-label`이 `{이름} 삭제`가 되고 테두리가 붉어진다.
**한 칩은 언제나 버튼 하나다.** 하는 일만 모드에 따라 바뀐다.

정리 모드에 들어가면 골라 둔 항목을 푼다. 점수를 주려다 지우는 일이 없어야 한다.

### 4.1 지워도 준 점수는 남는다

`deletePreset`이 이미 그렇게 만들어져 있다 — `ScoreEntry.reason`에 항목 이름이
**문자열로** 저장돼 있어, 항목을 지워도 기록은 온전하다.

삭제 확인창에 적는다.

> 이미 준 점수는 그대로 남습니다.

---

## 5. 테스트

**당번 대체**
- 대체를 지정하면 그 학생이 오늘 당번 목록에 나온다
- 원래 학생 이름이 `{이름} 대신`으로 함께 보인다
- `(대체 없음)`을 고르면 원래 당번으로 돌아온다
- 고를 수 있는 학생에 **오늘 그 역할 당번은 안 들어간다**
- 대체해도 다른 역할·다른 날은 안 바뀐다

**행동 항목 정리**
- 정리 모드에서 칩을 누르면 확인창이 뜬다
- 지우면 목록에서 사라진다
- **이미 준 점수는 그대로 남는다**
- 정리 모드에 들어가면 골라 둔 항목이 풀린다
- 정리 모드를 끄면 다시 고를 수 있다

**중첩 버튼 회귀 방지**
- 당번 학생 줄 안에 버튼이 없다
- 행동 항목 칩 안에 버튼이 없다
