# 교사 잠금과 오늘의 명언 설계

**날짜** 2026-08-16
**적용 대상** `G-classroom-suite` — `app` · `features/settings` · `features/home`
**계기** [`../../reference/missing-features-audit.md`](../../reference/missing-features-audit.md) B 목록 마지막 둘

---

## 1. 교사 잠금은 보안이 아니다

**무엇을 막나:** 교사가 자리를 비운 사이 학생이 지나가다 화면을 만지는 것.
전자칠판에 자리표를 띄워 두고 나갔는데 학생이 자리를 바꾸거나 점수를 주는 일.

**무엇을 못 막나:** 마음먹고 열려는 사람. PIN은 브라우저에 그대로 저장된다.
개발자 도구를 열면 보인다.

**이것을 화면에 적는다.** 설정 화면에서 "안전합니다"라고 말하지 않는다.
교사가 이 장치를 믿고 민감한 것을 남겨 두면 안 된다.

> 학생이 지나가다 실수로 누르는 것을 막는 장치입니다.
> PIN은 브라우저에 그대로 저장되므로 마음먹고 열려는 사람은 막지 못합니다.

### 1.1 이미 있는 `화면 가리기`와 다르다

`ToolsBar`에 `화면 가리기`가 있다. 그건 **수업 중 잠깐 가리는 도구**다 —
Esc나 버튼 한 번으로 걷히고, 걷히는 것이 목적이다.

교사 잠금은 반대다. **쉽게 걷히면 안 되고, 새로 고쳐도 남아야 한다.**
이름도 조작도 따로 둔다. 한 화면에 둘 다 있어도 헷갈리지 않아야 한다.

| | 화면 가리기 | 교사 잠금 |
|---|---|---|
| 거는 곳 | 아래 도구 막대 | 헤더 자물쇠 |
| 걷는 법 | Esc·버튼 | PIN 4자리 |
| 새로 고치면 | 걷힌다 | **남는다** |
| 쓸 때 | 수업 중 잠깐 | 자리를 비울 때 |

## 2. 모델

`SuiteData`에 둘을 더한다.

```ts
/** 교사 잠금 PIN 4자리. 빈 문자열이면 잠금을 쓰지 않는다. */
lockPin: string;
/** 지금 잠겨 있는가. 새로 고쳐도 남아야 하므로 저장한다. */
isLocked: boolean;
```

**잠긴 상태를 저장하는 것이 이 기능의 핵심이다.** 저장하지 않으면 새로 고침
한 번에 풀리고, 그러면 막는 것이 없다.

전자칠판은 터치 화면이라 키보드가 없는 경우가 많다. 그래서 학생이 F5를 누르기
어렵다는 점도 이 선택을 돕는다 — 하지만 그것에 기대지는 않는다.

---

## 3. 순수 함수 — `shared/lock/lockOps.ts`

```ts
export const PIN_LENGTH = 4;

/** 숫자 4자리인가. 그 외에는 저장하지 않는다. */
export function isValidPin(pin: string): boolean;

export function setPin(data: SuiteData, pin: string): SuiteData;
/** PIN을 지우면 잠금도 함께 풀린다. 열 방법이 없는 상태를 만들지 않는다. */
export function clearPin(data: SuiteData): SuiteData;
/** PIN이 없으면 아무것도 하지 않는다. */
export function engageLock(data: SuiteData): SuiteData;
export function tryUnlock(data: SuiteData, pin: string): { data: SuiteData; ok: boolean };
```

`clearPin`이 잠금까지 푸는 이유: PIN을 지웠는데 잠금이 남으면 **열 수 있는
값이 없는 잠긴 화면**이 된다. 자료를 초기화하는 것 말고는 길이 없다.

## 4. 잠금 화면

`AppShell`이 `data.isLocked`를 보고 전체 화면을 덮는다.

### 4.1 숫자 키패드를 그린다

**전자칠판에는 키보드가 없다.** 텍스트 입력칸만 두면 교사도 못 연다.
0~9 버튼과 지우기를 크게 그린다. 손가락으로 누르는 크기다.

물리 키보드가 있으면 숫자 키로도 입력된다. 둘 다 받는다.

### 4.2 네 자리를 채우면 바로 확인한다

`확인` 버튼을 따로 두지 않는다. 네 자리는 짧고, 버튼을 한 번 더 누르는 것은
잠금을 푸는 일에서 순수한 낭비다.

틀리면 입력을 지우고 알린다. **몇 번 틀렸는지 세지 않고 잠그지도 않는다.**
이 장치의 목적은 실수를 막는 것이지 침입을 막는 것이 아니다.
잠가 버리면 교사가 자기 앱을 못 쓰게 되는 쪽이 더 흔하다.

### 4.3 Esc로는 안 걷힌다

`화면 가리기`와 반대다. 걷히면 안 되니까 만든 것이다.

### 4.4 전자칠판 창은 덮지 않는다

`/board/*`는 보여 주려고 띄운 화면이다. 덮으면 목적과 충돌한다.
칠판에는 자료를 지우거나 바꾸는 조작이 없다 — 보기와 화면 전환뿐이다.

## 5. 설정 화면

`설정`에 `교사 잠금` 카드를 더한다.

| 지금 | 보이는 것 |
|---|---|
| PIN 없음 | PIN 만들기 (4자리 입력 두 번) |
| PIN 있음 | 지금 잠그기 · PIN 바꾸기 · 잠금 해제 |

§1의 안내 문구를 카드 안에 적는다.

헤더에는 **PIN이 있을 때만** 자물쇠 버튼이 나온다. 쓰지 않는 교사에게
누를 수 없는 버튼을 보일 이유가 없다.

---

## 6. 오늘의 명언

홈 화면 카드 하나. 원본 대시보드에 있던 것이다.

### 6.1 목록은 내장한다

한국 속담·사자성어·널리 쓰이는 교육 격언으로 30개쯤 넣는다.
**저작권이 살아 있는 문장은 넣지 않는다.** 속담과 사자성어는 문제가 없다.

교사가 자기 문구를 넣는 기능은 만들지 않는다. 우선순위가 낮고,
직접 띄우고 싶으면 아래 도구 막대의 `알림 띄우기`가 이미 있다.

### 6.2 날짜로 고른다

```ts
export function quoteOfDay(today: string, quotes?: readonly Quote[]): Quote;
```

연중 며칠째인지를 목록 길이로 나눈 나머지를 쓴다.
**같은 날에는 같은 명언이 나온다.** 새로 고칠 때마다 바뀌면
"아까 그 문장 뭐였지"를 다시 찾을 수 없다.

카드에 `다른 명언` 버튼을 둔다. 오늘 것이 마음에 안 들 때 넘긴다.
넘긴 것은 저장하지 않는다 — 새로 고치면 오늘 것으로 돌아온다.

---

## 7. 테스트

**`lockOps`**
- 숫자 4자리가 아니면 저장하지 않는다 (`123`·`12345`·`abcd`·빈 문자열)
- PIN을 지우면 잠금도 풀린다
- PIN이 없으면 잠기지 않는다
- 맞는 PIN이면 풀리고 틀리면 그대로다

**잠금 화면**
- 네 자리를 채우면 바로 확인한다
- 틀리면 입력이 지워지고 잠긴 채로 남는다
- Esc를 눌러도 안 걷힌다
- 키패드 숫자 버튼이 10개 있다

**`quoteOfDay`**
- 같은 날에는 같은 명언이 나온다
- 다른 날에는 (대체로) 다른 명언이 나온다
- 목록이 하나뿐이어도 깨지지 않는다
- 읽을 수 없는 날짜에도 하나를 돌려준다
