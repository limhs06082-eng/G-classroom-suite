# 0.18.0 — 연수 묶음 ①: 샘플 학급·생일·알림장 문자 복사·첫 화면 안내 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 연수 자리에서 30초 만에 "우리 반"이 서고(샘플 학급), 교실이 "와" 하는 생일 카드가 뜨고, 알림장을 문자로 붙일 수 있고, 처음 켠 사람이 설명 없이 돌아다닐 수 있게(첫 화면 안내) 한다.

**Architecture:** 샘플은 순수 함수 `createSampleClass(data, today, now)`가 기존 factories·rosterOps·groupingCore로 한 벌을 만들고 `isSample` 표시로 되돌린다(마지막 학급 보호를 우회하는 `removeClassData` 분리). 생일은 `Student.birthday?`(YYYY-MM-DD) + 순수 `birthdayCore` + 홈 카드·오늘 보드 섹션 + 명단 붙여넣기의 날짜 열 인식. 알림장 문자는 `noticeText()` 순수 함수 + 클립보드. 첫 화면 안내는 홈 위의 4단계 카드(기기 localStorage `gboard:tips-seen`).

**Spec:** `docs/reference/training-demo-proposal.md` 1·2·3·5. 사용자 지시 2026-09-05 "1, 2, 3, 5를 한 묶음으로".

## Global Constraints

- 스키마 판 4 유지(선택 필드만 늘어난다: `Student.birthday?`, `ClassRoom.isSample?`, `Term.isSample?`).
- 샘플 자료는 `validateAndRepair`에 repairs 0건으로 통과해야 한다(번호 유일, 프로필 있음).
- 샘플 만들기·지우기는 `guard()`로 직전 백업.
- 생일은 이름·번호처럼 자료에 산다(백업 포함). 문자 복사 본문에 학생 이름은 들어가지 않는다(알림장 항목만).
- 첫 화면 안내는 기기 취향(localStorage). 설정에서 다시 볼 수 있다.
