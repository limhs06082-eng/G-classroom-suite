# 0.19.0 — 연수 묶음 ②: 주간 안내문 인쇄·교시 끝 알림음·거수 투표·상담 기록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docs/reference/training-demo-proposal.md`의 나머지 넷(4·6·7·8)을 붙인다.

**Architecture:** 순수 함수 먼저(`weekOf`·`eventsBetween`, `shouldChime`, `voteCore`, `nextCounsel`), 화면은 기존 틀에 얹는다. 주간 안내문은 알림장의 모달에서 이번 주/다음 주와 한마디를 받아 그때만 `PrintLayout`을 마운트한다(인쇄 포털은 마운트된 것을 전부 찍으므로). 알림음은 기기 설정(localStorage)이고 기본은 **꺼짐** — NowCard의 "소리는 내지 않는다" 결정을 설정으로 옮긴다. 거수 투표는 툴바의 다섯째 도구(설정 모달 → 크게 띄우기 오버레이, NoticeModal 패턴). 상담 기록은 `ObservationEntry.kind?: 'counsel'`·`followUpDate?`.

**Spec:** 사용자 지시 "나머지도 개선하고 오류 검증".

## Global Constraints

- 스키마 판 4 유지(선택 필드만).
- 알림음 기본 꺼짐. 전체 음소거가 켜져 있으면 안 울린다(`playChime`이 이미 그렇다). 같은 교시에 한 번만(홈과 오늘 보드가 같이 떠 있어도).
- 주간 안내문을 찍는 동안 알림장의 하루 인쇄 포털은 내려 둔다.
- 투표는 기록하지 않는다(그 자리에서 쓰고 끝). 선택지 2~4개, 손 든 수는 교사가 탭.
