자료에 남는 홈 배치·좌석 미리보기·사유 분류 판

홈 배치가 백업과 다른 컴퓨터에 따라가고, 자리·모둠 카드를 넓히면 자리표가 보이고, 출결 사유에 생활기록부 분류가 붙습니다.

## 새로 된 것

- **홈 카드 배치가 자료에 남습니다** — 순서·숨김·크기가 백업 파일에 들어가고, 교실 PC와 집 노트북이 같은 배치를 봅니다. 지금까지 이 컴퓨터에만 있던 배치는 처음 켤 때 한 번 자동으로 옮겨집니다.
- **자리·모둠 카드 자리표 미리보기** — 홈에서 자리·모둠 카드를 [넓히기]로 두 칸 이상 만들면 카드 안에 지금 자리표가 작게 보입니다. 누르면 자리 화면으로 갑니다.
- **출결 사유 분류** — 오늘 출결의 사유 메모 줄에 **질병 · 미인정 · 기타 · 인정** 네 단추가 생겼습니다. 메모("병원")와 별개로 누르면 켜지고 다시 누르면 꺼집니다. 학기 전체 표의 사유 열에 "3/5 결석(질병): 병원"처럼 같이 나옵니다.

## 알아 둘 것

- 자료 형식이 3판이 됐습니다. 이 판으로 만든 백업을 0.14.0 이전 앱에서 열면 "새 판 자료" 경고가 뜹니다 — 앱을 먼저 갱신하면 됩니다.

## 설치

새 판 알림의 [지금 설치]를 누르면 됩니다. 손으로 설치하려면 `G-board_0.15.0_x64-setup.exe`를 받아 더블클릭하세요. 처음 실행 때 "PC 보호" 창이 뜨면 **추가 정보 → 실행**.
