학급 게시판 — 학생과 함께 쓰기 판

선생님의 Firebase를 연결하면 학생이 링크·QR로 들어와 글과 댓글을 쓰는 학급 게시판이 생깁니다. 설치형과 웹 모두.

## 새로 된 것

- **학급 게시판** — 내비에 '학급 게시판'. 학급마다 하나, 안에 주제 탭(건의함·칭찬 릴레이·자유 이야기, 이름 바꾸기·추가·잠그기). 글은 제목 없이 본문 한 덩어리, 댓글은 그 아래. 좋아요·사진·파일은 없습니다.
- **학생은 링크·QR로** — 계정 없이 이름(또는 별명)만 적고 들어옵니다. 링크에 선생님의 Firebase 설정값이 실려 가서, 설치형 선생님도 공식 웹 배포 하나로 학생을 받습니다. 한 번 들어온 폰은 코드만으로 다시 들어옵니다.
- **선생님은 앱 안에서** — 글·댓글 숨기기·지우기, 주제 잠그기(방학 중), 별명만 받기, 게시판 닫기. 숨긴 글은 학생이 읽지 못하도록 규칙이 막습니다.
- **설정 → 학급 게시판** — 콘솔에서 복사한 firebaseConfig를 통째로 붙여 넣으면 됩니다. [연결 확인]이 익명 로그인·Firestore·규칙을 차례로 짚어 무엇을 빠뜨렸는지 말해 줍니다. 규칙은 [규칙 복사]로.
- **무료로 충분하게** — 화면을 열 때와 [새로고침]에만 읽습니다(실시간 구독 없음). Firestore lite를 써서 꾸러미도 작습니다.
- README에 선생님용 연결 순서(10분)를 적었습니다.

## 설치

새 판 알림의 [지금 설치]를 누르면 됩니다. 손으로 설치하려면 `G-board_0.21.0_x64-setup.exe`를 받아 더블클릭하세요.

게시판을 쓰려면 Firebase 프로젝트가 필요합니다 — README '학급 게시판' 절, 또는 설정 → 학급 게시판 탭의 순서를 따라 하세요. 안 붙여도 나머지 기능은 전과 같습니다.
