샘플 학급·생일·문자 복사·첫 안내 판

연수 자리를 위한 묶음입니다. 30초 만에 "우리 반"이 서고, 오늘 생일이 카드와 TV에 뜨고, 알림장을 문자로 붙이고, 처음 켠 사람이 설명 없이 돌아다닙니다.

## 새로 된 것

- **샘플 학급** — 처음 설정 마법사의 학급 단계와 설정 → 학급·학기 탭에 [샘플 학급 만들기]. 가짜 학생 24명에 시간표·일정·칭찬·관찰·출결·과제·모둠·자리·당번·알림장·쿠폰이 한 벌로 들어옵니다. 홈 위 노란 띠의 [샘플 지우기]로 흔적 없이 되돌립니다.
- **생일** — 학생 정보에 생일 칸. 명단 붙여넣기에 생년월일 열(2015-09-07, 2015.09.07, 20150907, 2015년 9월 7일)이 있으면 저절로 들어옵니다. 홈 '생일' 카드에 오늘 생일과 한 달 안 생일, 오늘 보드 맨 위에 "🎂 오늘 생일".
- **알림장 [문자로 복사]** — 항목·과제·다가오는 일정을 한 덩어리 글로 복사해 e알리미·카톡·하이클래스에 붙여 넣습니다.
- **첫 화면 안내** — 처음 켜면 홈 위에 네 걸음 안내가 뜨고 해당 카드를 파랗게 가리킵니다. 한 번 보면 이 컴퓨터에서는 다시 안 뜨고, 설정 → 화면 → [처음 안내 다시 보기]로 다시 볼 수 있습니다.

## 설치

새 판 알림의 [지금 설치]를 누르면 됩니다. 손으로 설치하려면 `G-board_0.18.0_x64-setup.exe`를 받아 더블클릭하세요. 처음 실행 때 "PC 보호" 창이 뜨면 **추가 정보 → 실행**.
