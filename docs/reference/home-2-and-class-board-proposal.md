## 1. 홈 2.0 — 왜 지금 홈이 불편한가

| 지금 | 그림에서 배운 것 |
|---|---|
| 카드가 전부 **요약 + "열기" 링크**다. 홈에서 할 수 있는 일이 없고, 뭘 하든 한 번 더 들어가야 한다. | 카드 머리에 **바로 하는 단추**가 있다(+ 글쓰기, + 추가, 예약하기). 홈에서 적고 끝낸다. |
| 카드 열 개가 같은 크기로 3열에 늘어서 있다. 아침에 보는 것과 학기말에 보는 것이 같은 무게다. | 첫 줄은 **오늘 것**(일정·공지·알림장·회의·소통), 둘째 줄은 **넓은 표·목록**(D-day, 바로가기, 예약표, 급식). 줄마다 역할이 있다. |
| 카드 조작(끌기·넓히기·숨기기)이 마우스를 올려야 보인다. 처음 온 사람은 모른다. | 카드 머리 오른쪽에 **접기(^)·새로고침·열기(↗)**가 늘 보인다. |
| 도구(타이머·뽑기…)가 하단 막대의 작은 글자 단추다. | **업무 바로가기**처럼 아이콘 격자. 손가락으로 눌린다. |
| D-day가 일정 카드 안에 셋만. | **주요 일정** 카드가 D-day 열 개를 한 줄에 하나씩, 숫자를 오른쪽 정렬로. |

### 제안 (0.20.0 한 판)

1. **카드 머리를 통일** — 왼쪽 아이콘·제목·한 줄 부제, 오른쪽 [접기 ^]·[열기 ↗]. 접힘은 배치(`homeLayout.collapsed`)에 저장. 끌기·넓히기·숨기기는 지금처럼 마우스를 올리면 나오되, [열기 ↗] 옆 "…"에도 넣어 처음 온 사람이 찾게 한다.
2. **홈에서 바로 하는 일 셋** —
   - 알림장 카드: 오늘 항목이 보이고, **입력칸이 카드 안에** 있다(Enter로 추가). 그림의 "오늘의 알림장 + 추가".
   - 출결 카드: 결석·지각 이름과 함께 **[전원 출석 확인]** 단추. 아무도 안 빠진 날은 홈에서 끝난다.
   - 일정 카드: **[+ 일정]**으로 제목·날짜만 받는 작은 창.
3. **기본 배치를 두 줄로** — 첫 줄(오늘): 지금 · 오늘 출결 · 오늘 시간표 · 급식 · 생일. 둘째 줄(넓게): 오늘 알림장(2칸) · 주요 일정 D-day(1칸, 열 개) · 당번 · 점수. 셋째 줄: 자리(2칸, 자리표 미리보기 기본 켬) · 과제 · 명단. 이미 있는 `sizes`로 기본값만 바꾸면 된다. 교사가 옮긴 배치는 그대로 존중한다.
4. **도구 격자** — 하단 막대는 두고, 홈 맨 아래에 타이머·뽑기·거수 투표·화면 가리기·알림 띄우기·오늘 보드를 아이콘 격자로. 그림의 "업무 바로가기".
5. **머리띠 한 줄** — 학교·학급·오늘 날짜(요일)를 왼쪽에, [오늘 보드]·[설정]을 오른쪽에. 지금은 두 줄이라 화면 위쪽이 두껍다. 기능 내비는 아이콘만 남기고 글자는 마우스를 올리면.
6. **밀도** — 카드 안 목록 줄 간격을 그림처럼 좁히고(`gap-1`·`text-sm`), 카드 최소 높이를 없앤다. 큰 화면에서 스크롤 없이 홈이 한 화면에 들어오는 것이 목표다.

크기: 중~대(홈 파일이 이미 900줄이라 카드를 파일로 나누는 정리가 같이 든다). 시험은 지금의 홈 배선 시험을 그대로 쓰고, 카드마다 "홈에서 바로 하기" 시험 하나씩 더한다.

## 2. 학급 게시판 — 선생님의 Firebase로, 학생과 함께

### 지금 있는 것

- 웹 판에는 이미 Firebase가 붙어 있다(`src/shared/storage/firebaseApp.ts`, `FirestoreAdapter.ts`, 계정·동기화 탭). 다만 설정값이 **소스 파일(`firebaseConfig.ts`)에 박혀** 있어 배포하는 사람이 채운다. 설치형(.exe)에서는 안 쓴다.
- 형성평가에 학생 참여 화면(`/join/:code`)과 웹 중계(`QuizSessionRelay`)가 있다 — "학생이 링크로 들어와 참여한다"는 틀이 이미 있다.

### 제안

**사용자가 자기 Firebase 설정값을 넣는다** — 설정 → 계정·동기화(웹) / 새 탭 "학급 게시판"(설치형·웹 공통)에 Firebase 웹 앱 설정 JSON(apiKey·authDomain·projectId·appId)을 붙여 넣는 칸. 이 컴퓨터에만 저장(AI 키와 같은 원칙). 붙여 넣으면 [연결 확인].

**게시판 모양 — 글과 댓글만**
- 게시판은 학급마다 하나, 안에 **주제 탭**을 교사가 만든다: 건의함 · 칭찬 릴레이 · 자유 이야기 (기본 셋, 이름 바꾸기·추가 가능).
- 글: 제목 없이 본문 한 덩어리(문자처럼) + 쓴 사람 + 시각. 댓글: 본문 + 쓴 사람. 좋아요·사진·파일은 넣지 않는다 — 개인정보와 운영 부담이 늘고, 없어도 건의·칭찬은 된다.
- 학생 입장: 교사가 만든 **학급 코드 링크/QR**(`/board/join/:code`)로 들어온다. 이름은 명단에서 고르거나(교사가 켠 경우) 별명을 친다. 건의함은 **익명**으로 둘 수 있다(교사에게만 이름이 보임).
- 교사 입장: 앱 안 "게시판" 화면에서 같은 글을 보고, 글·댓글을 **숨기기/지우기**, 주제 잠그기(방학 중), 오늘 보드에 "칭찬 릴레이 최근 3개" 띄우기.

**안전과 비용**
- 학생은 계정 없이 **익명 로그인**(Firebase Anonymous Auth)으로 들어온다. Firestore 규칙은 `boards/{classCode}/...`에 대해 "로그인했고 코드가 맞는" 요청만 읽고 쓰게 한다. 교사(이메일 로그인)만 숨기기·지우기. 규칙 파일을 앱이 만들어 주어 복사해 붙이게 한다.
- 무료 한도(Firestore 하루 읽기 5만·쓰기 2만, 익명 로그인 무제한)는 한 학급 30명이 매일 써도 남는다. 다만 "제한이 없다"기보다 **한 반 규모에서는 부딪히지 않는다**가 정확하다. 화면은 실시간 구독 대신 **열 때 한 번 읽기 + [새로고침]**으로 두어 읽기 수를 아낀다.
- 학생 이름·글이 교사의 Firebase에 저장된다는 점을 설정 화면에 적는다. 학교 개인정보 지침에 따라 별명만 쓰게 하는 스위치를 둔다.

**설치형에서의 통신** — Firestore SDK는 브라우저 `fetch`로 `firestore.googleapis.com`에 붙는다(Tauri http 플러그인이 아니라). 그래서 `tauri.conf.json`의 CSP `connect-src`에 `https://firestore.googleapis.com https://identitytoolkit.googleapis.com https://securetoken.googleapis.com`을 더해야 하고, `check-release`의 CSP 검사(`*` 금지)는 그대로 지키면서 이 셋만 허용하도록 검사 목록을 늘린다.
