# 연수 시연을 위한 개선안 — "아, 이거 꼭 쓰겠다"가 나오는 것만

2026-09-05. 0.17.0까지 붙은 것을 전제로, 담임교사가 시연 자리에서 바로 마음이 움직일 것을 골랐다.
기준은 하나다. **선생님이 이미 매주 하고 있는 일**을 이 앱이 한 번에 끝내 주는가.
그렇지 않은 기능(학급 회계, 채팅, 소셜, 통계 대시보드)은 넣지 않는다.

## 시연 자리에서 먹히는 것 (지금 있는 것)

| 장면 | 보여 줄 것 |
|---|---|
| 아침 5분 | 명단 붙여넣기 → 출결 탭 → 오늘 보드를 TV에 |
| 수업 중 | 뽑기 룰렛 · 타이머 · 화면 가리기 · 모둠 점수판 |
| 종례 | 알림장 칩(일정·자주 쓰는 문구) → 인쇄 |
| 학기말 | 출결 학기 집계(분류별) → 행동특성 한 번에(AI) → 나이스 붙여 넣기 |
| 안심 | 자동 갱신 · 백업 · 잠금 · 키·이름이 밖으로 안 나가는 설계 |

## 다음 판에 넣을 것 (추천 순)

| 1 | **샘플 학급 한 번에 만들기** (설정·처음 설정 마법사) | 연수생 30명이 각자 자기 노트북에서 30초 만에 "우리 반"을 눌러 볼 수 있어야 한다. 지금은 명단부터 넣어야 첫 화면이 산다. 가짜 이름 24명·시간표·일정·칭찬 기록·관찰 기록까지 한 벌. [샘플 지우기]로 되돌린다 | 중 |

## 시연 순서 제안 (20분)

1. (2분) 설치 파일 하나 → 켜기 → **샘플 학급** 만들기 → 홈이 찬다.
2. (5분) 아침: 출결 탭 → 오늘 보드를 TV에 → 급식·시간표·생일·당번이 한 화면.
3. (5분) 수업: 뽑기 룰렛 → 타이머 → 모둠 점수 → 목표 달성 축하.
4. (5분) 학기말: 출결 학기 집계 → 행동특성 한 번에 → [AI로 모두 작성] → 나이스 붙여 넣기.
5. (3분) 안심: 백업 내보내기 파일 열어 보이기(키 없음), 자동 갱신 알림, `?` 단축키.

## 넣지 않을 것

- 학급 회계·준비물 구매 관리 — 학교 행정 시스템과 겹치고 돈 얘기는 앱이 책임질 수 없다.
- 학부모·학생 채팅, 학급 SNS — 개인정보와 운영 부담. 이 앱은 교사 혼자 쓰는 도구다.
- 통계 대시보드(그래프) — 담임이 보는 것은 "누가 아직 안 냈나"이지 추세선이 아니다.
- 웹 퀴즈 Firebase 중계 — 연수 범위 밖. 설치형만으로 시연이 된다.
- 학생이 폰으로 들어오는 게시판·설문 — 선생님마다 자기 Firebase와 웹 배포가 필요하다. 0.21.0에서 만들었다 걷어냈다(2026-09-06).
