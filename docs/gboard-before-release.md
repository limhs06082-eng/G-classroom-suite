# G-board, 배포 전에

이 문서는 선생님용이 아니다. 만드는 사람용이다. 설치 파일을 이 기기
밖으로 내보내기 전에 참이어야 하는 것들을 적는다. 2판 이후에 할 일
(`docs/superpowers/plans/`)과는 별개로, **1판 설치형을 처음 내보낼 때**
반드시 짚어야 하는 목록이다.

## 막아야 하는 것

- **단일 인스턴스 잠금이 없다.** 앱을 두 번 띄우면 두 인스턴스가 각자
  자료 전체를 메모리에 들고 같은 `data.json`을 통째로 덮어쓴다. 충돌도,
  경고도, 되돌릴 길도 없다 — `backups.json` 말고는. 게다가 두 인스턴스가
  같은 `data.json.tmp`를 쓰므로, 한쪽의 `rename`이 다른 쪽 임시 파일을
  가져가 **본 파일도 임시 파일도 없는 순간**이 생길 수 있다. 선생님은
  바탕화면 아이콘을 두 번 누른다. `tauri-plugin-single-instance` 하나와
  `lib.rs` 네 줄이면 막는다.

## 확인해야 하는 것

- 아직 아무도 설치형 앱을 실제로 켜 본 적이 없다 — `docs/gboard-first-run.md`의
  사람 확인 목록을 한 번은 통과해야 한다.

## 받아들이고 넘어가는 것

- 코드 서명이 없어 윈도우가 "알 수 없는 게시자" 경고를 띄운다. 1판에서는
  의도한 것이고, `docs/gboard-first-run.md`의 안내로 넘긴다.
