# G-board, 배포 전에

이 문서는 선생님용이 아니다. 만드는 사람용이다. 설치 파일을 이 기기
밖으로 내보내기 전에 참이어야 하는 것들을 적는다. 2판 이후에 할 일
(`docs/superpowers/plans/`)과는 별개로, **1판 설치형을 처음 내보낼 때**
반드시 짚어야 하는 목록이다.

## 막아야 하는 것

지금은 없다. 마지막으로 있던 단일 인스턴스 잠금은 닫았다 — 아래 "닫은
것" 참고.

## 닫은 것

- **단일 인스턴스 잠금.** 앱을 두 번 띄우면 두 인스턴스가 각자 자료
  전체를 메모리에 들고 같은 `data.json`을 통째로 덮어써, 선생님이
  바탕화면 아이콘을 두 번 눌렀을 뿐인데 1년치 기록이 경고 한 줄 없이
  사라질 수 있었다. `tauri-plugin-single-instance`를 다른 모든
  `.plugin(...)`보다 먼저 등록해, 두 번째로 뜬 프로세스가 `data.json`을
  열어보기도 전에 곧장 끝나고 이미 켜진 창만 앞으로 불러오게 막았다.
  (`gboard/single-instance` 브랜치)

## 확인해야 하는 것

- 설치형 앱은 이제 여러 차례 실제로 켜서 확인했고, 그 과정에서 나온
  문제(창 권한이 빠져 앱이 안 닫히고 전자칠판이 안 열리던 것, 전자칠판이
  보조 모니터에 갇히던 것, 저장 실패가 화면에 안 보이던 것)는 각각 찾아서
  고쳤다. 다만 **단일 인스턴스 동작 자체**는 아직 사람이 눈으로 확인하지
  않았다 — 아이콘이 이미 떠 있는 상태에서 한 번 더 눌렀을 때 창이 두 개가
  아니라 하나만 뜨고 그 창이 앞으로 나오는지는, 에이전트가 GUI 인스턴스를
  두 개 띄워 눈으로 볼 수 없어 확인이 안 된 채로 남는다.
  `docs/gboard-first-run.md`의 사람 확인 목록에 줄을 추가해 뒀다.

## 받아들이고 넘어가는 것

- 코드 서명이 없어 윈도우가 "알 수 없는 게시자" 경고를 띄운다. 1판에서는
  의도한 것이고, `docs/gboard-first-run.md`의 안내로 넘긴다.
